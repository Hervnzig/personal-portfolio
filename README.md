## 🚀 Featured projects

### 🎥 [Verity (`proctor-buddy`)](https://github.com/Hervnzig/proctor-buddy)
A web-based proctoring MVP for lecturer-led quiz sessions. Students join through an invite link, share their webcam and screen, and complete a background check; lecturers review and approve them, then monitor live streams and an activity log. Face-presence checks run on-device, and each session produces a downloadable JSON report. Built with a focus on consent, transparency, and privacy.

`React` `Node.js` `WebRTC` `WebSockets` `MediaPipe` `Vite`

### 🗺️ [ArcGIS API Web Application (`arcgisAPI_app`)](https://github.com/Hervnzig/arcgisAPI_app)
An interactive mapping app on top of the ArcGIS API. Users can create, edit, and delete points, lines, and polygons, manage layers, search by coordinates, and filter data with charts that stay in sync with the map. Visualizes transport station data alongside regional and provincial boundaries.

`React` `JavaScript` `ArcGIS API` `GeoJSON`
